    symmetryNumber: number | null

    Rotational symmetry number σ, or null to take it from the detected point group. It enters the rotational entropy as −R·ln σ, so a wrong value is a silent error in ΔG — benzene at σ=1 instead of 12 is ~1.5 kcal/mol out.
